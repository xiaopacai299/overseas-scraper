## 二、六大海外平台差异、数据量阶梯报价与成本对照表

不同平台的反爬机制天差地别，**绝对不能所有平台一口价**！接单前先看客户要抓哪个平台、多少条：

### 🟢 第一梯队：零成本免登录平台（YouTube、Reddit、HackerNews、普通海外公开网）
- **技术特点**：纯 Python 脚本（`yt-dlp` / 公开 `.json` / `BeautifulSoup`）配合你现有的本地代理即可直接跑，**0 账号成本、0 接口费、不封号**。
- **采集耗时**：1,000 条约 1~3 分钟；10,000 条约 8~15 分钟。

| :--- | :--- | :--- | :--- |
| **500 条以内**（小单/验货单） | **39 ~ 68 元** | **99 ~ 158 元** | **0 元** |
| **500 ~ 3,000 条**（标准论文单） | **68 ~ 128 元** | **168 ~ 238 元** | **0 元** |

### 🟡 第二梯队：半开放平台（TikTok 视频列表与评论）
- **技术特点**：视频列表可用 `yt-dlp` 直接抓；但大批量抓评论需要 **CDP 接管浏览器滚动** 或 **调用第三方采集池（如 Apify）**。
- **采集耗时**：1,000 条约 5 分钟；10,000 条约 15~30 分钟。

| 客户需求数据量 | A 档：仅交付 Excel+CSV 数据 | B 档：数据 + Python 源码 | 你的硬性成本与方式 |

### 🔴 第三梯队：强登录/强风控平台（Facebook、Instagram `ig/ins`、X `Twitter`）
- **技术特点**：**未登录 100% 无法查看评论！** 且单账号高频硬爬超过 500~1000 条极易触发验证码或封号。
- **核心策略**：
  - **小单（500 条内）**：用本地已登录的 Edge 浏览器通过 CDP 脚本模拟真人滚动提取（0 成本）。
  - **大单（1,000 ~ 10,000+ 条）**：千万别拿自己主力号硬爬，直接用 **Apify** 现成 Scraper 跑出 JSON 再用我们的 `exporter.py` 转双份 Excel（每万条成本仅 $1.5~$2.5 美元，且新号送 $5 免费额度）。

| **500 条以内** | **88 ~ 138 元** | **220 ~ 320 元** | **0 元**（浏览器接管滚动） |
| **500 ~ 3,000 条** | **138 ~ 240 元** | **280 ~ 420 元** | **约 3 ~ 8 元**（Apify 免费额度可抵扣） |

## 三、当客户抓 Facebook / Ins / X 且「既要数据又要 Python 代码」时的 2 种标准应对方案

遇到强风控平台还要代码的客户，**拍前必须发下面这段话问清楚他的用途**，防止他以为一行 `requests.get('https://facebook.com')` 就能无号无限爬：

### 场景 1：客户是学生写论文，要代码是为了「放进论文附录 / 交作业 / 跑小样本演示」（最常见，占 80%）
- **怎么给代码（0 成本）**：
  我们直接给他生成一套 **《Python + Playwright 浏览器自动化采集 + Pandas/OpenPyXL 清洗导出源码》**。
- **发给客户确认的话术**：
  > “Facebook / Ins / X 这类平台官方强制要求登录才能查看评论。我发你的全套 Python 源码是基于 **Playwright 浏览器自动化（复用本地浏览器登录态 Cookie）+ 自动向下滚动解析 DOM + 自动清洗导出 Excel** 编写的纯 Python 代码，代码结构清晰、带完整中文注释，直接放论文附录或本地挂载你自己的账号跑小样本完全没问题！同时本次你需要分析的 XXX 条完整 Excel 数据集我会先在工作室专线环境全部跑好一并发你！”

### 场景 2：客户是商业买家，想拿代码自己每天在本地大批量爬几万条 FB / Ins / X
- **怎么给代码（不替他掏后续 API 费）**：
  提供 **「方案一：CDP 浏览器接管版源码（需他自备账号与代理，单次建议几百条）」** 或 **「方案二：Python 对接海外云采集池（Apify SDK）源码（可日采数万条免封号）」**。
